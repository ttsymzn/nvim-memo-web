nvim-memo

GitHub の Fine-grained Personal Access Token で接続します。

token の作り方
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories で nvim-memo だけを選ぶ
  3. Permissions → Repository permissions → Contents: Read and write

token はこのブラウザ内（IndexedDB）にだけ保存されます。:Logout で削除できます。
