# Vim キーバインド説明書

nvim-memo-web で**いま実際に使える**キー操作の一覧。
エディタ部分は [`@replit/codemirror-vim`](https://github.com/replit/codemirror-vim) 6.2.1 の上に、
LazyVim 風のキーマップとメモアプリ用の Ex コマンドを足したもの。

- leader キーは `<Space>`（表記は `<leader>`）
- 「本アプリ独自」と書いたものは Neovim / codemirror-vim 標準と挙動が違うか、追加したもの

---

## 1. 画面とモード

| 画面 | 説明 |
|---|---|
| ダッシュボード | 起動直後・全バッファを閉じたとき・`:Dashboard` で表示されるメモ一覧 |
| エディタ | メモを編集する画面。上にバッファライン（開いているメモのタブ）、下にステータスラインとコマンドライン |
| プレビュー | `<leader>cp` / `:MarkdownPreview` でエディタの横に出る Markdown の表示（[9 章](#9-markdown-プレビュー本アプリ独自)） |

エディタのモードは Normal / Insert / Visual（`v` `V` `<C-v>`）/ Replace（`R`）。
行番号は LazyVim と同じく **相対行番号**（カーソル行だけ絶対番号）。

---

## 2. 本アプリ独自のキー（エディタ）

| キー | モード | 動作 |
|---|---|---|
| `<C-s>`（Mac は `⌘S` も可） | 全モード | 保存（`:w` と同じ） |
| `H` | Normal | 前のバッファ（`:bprevious`）。※標準の「画面上端へ」は上書き |
| `L` | Normal | 次のバッファ（`:bnext`）。※標準の「画面下端へ」は上書き |
| `<leader><leader>` | Normal | メモ一覧（ダッシュボード） |
| `<leader>ff` | Normal | メモ一覧（M2 で fuzzy picker に置き換え予定） |
| `<leader>fn` | Normal | タイムスタンプ名の新規メモを作り、Insert モードで開く |
| `<leader>bd` | Normal | 今のバッファを閉じる（`:bd`） |
| `<leader>qq` | Normal | 全バッファを閉じる（`:qa`） |
| `<leader>cp` | Normal | Markdown プレビューの表示 / 非表示（`:MarkdownPreviewToggle`） |
| `<leader>ww` | Normal | エディタとプレビューの間でフォーカスを移す（`<C-w>w`） |
| `<leader>wd` | Normal | プレビューを閉じる（`<C-w>c`） |
| `<C-w>` + `w` `h` `j` `k` `l` `p` `c` `q` `o` | Normal | ウィンドウ操作（[9 章](#9-markdown-プレビュー本アプリ独自)） |

leader の補足:

- `<Space>` を押すとコマンドラインに `<leader>` と表示され、続くキーを待つ。**1 秒**押さないか `Esc` で取り消し。
- 割り当てのない組み合わせは `<leader>xx は割り当てられていません` と表示される。
- `f<Space>` や `d<Space>` のように、文字やモーションを待っている途中の `<Space>` は leader にならず、そのまま Vim に渡る。
- 標準 Vim の `<Space>`（= `l`、右へ 1 文字）は leader に置き換わっているので使えない。

## 3. Ex コマンド

エディタでは `:` で、ダッシュボードでも `:` で入力できる。

### ファイル・バッファ（本アプリ独自）

| コマンド | 動作 |
|---|---|
| `:w` / `:write` | 保存。既存メモは `[nb] Edit:`、新規は `[nb] Add:` の 1 コミット（新規なら `.index` にも追記）。`:w <名前>` は未対応 |
| `:wa` / `:wall` | 変更のある全バッファを保存 |
| `:q` / `:quit` | 今のバッファを閉じる。未保存なら `E37` で止まる |
| `:q!` | 変更を破棄して閉じる |
| `:qa` / `:qall` | 全バッファを閉じてダッシュボードへ。`:qa!` で未保存も破棄 |
| `:wq` | 保存して閉じる |
| `:x` / `:xit` | 変更があれば保存して閉じる（なければそのまま閉じる） |
| `:e <名前>` / `:edit <名前>` | メモを開く。無ければ新規作成。拡張子を省略すると `.md` |
| `:e` | 今のメモをリモートの内容で読み直す（未保存なら `E37`） |
| `:e!` | 変更を破棄して読み直す |
| `:new` | タイムスタンプ名の新規メモ |
| `:bn` / `:bnext`、`:bp` / `:bprevious` | 次 / 前のバッファ |
| `:bd` / `:bdelete`（`:bd!`） | 今のバッファを閉じる |
| `:ls` / `:buffers` | バッファ一覧（`%a` = 表示中、`+` = 未保存） |
| `:Delete [名前]`（`:Delete!`） | メモをリポジトリから削除（`[nb] Delete:` で 1 コミット、`.index` からも消す）。`y` で確定、`!` なら確認なし。名前を省くとエディタでは今のメモ、ダッシュボードでは選択中のメモ |
| `:Dashboard` | メモ一覧を開く |
| `:MarkdownPreview` / `:MarkdownPreviewStop` / `:MarkdownPreviewToggle` | Markdown プレビューを開く / 閉じる / 切り替え |
| `:wincmd {c}`（`:winc`） | `<C-w>{c}` と同じ（例: `:wincmd w`） |
| `:close`（`:clo`）、`:only`（`:on`） | プレビューを閉じる |
| `:Sync` | リモート（GitHub）の変更を取り込む |
| `:Logout` | 保存している GitHub token を削除してログアウト |

### codemirror-vim 標準（エディタ内のみ）

| コマンド | 動作 |
|---|---|
| `:s/pat/rep/[gci]` / `:%s/…` | 置換（範囲指定・`c` で確認） |
| `:g/pat/cmd`、`:v/pat/cmd` | 一致する行 / しない行にコマンド実行 |
| `:d`、`:y`、`:j` | 行の削除・ヤンク・結合（範囲指定可） |
| `:normal {keys}` | Normal モードのキーを実行 |
| `:sort` | 行のソート（`!` で逆順、`n` 数値、`u` 重複除去 など） |
| `:noh` | 検索ハイライトを消す |
| `:u` / `:redo` | アンドゥ / リドゥ |
| `:set {opt}` | オプション変更（例 `:set ignorecase`） |
| `:reg` | レジスタの中身を表示 |
| `:delm {marks}` | マークを削除 |
| `:{数字}` | その行へ移動 |
| `:map` `:nmap` `:noremap` など / `:unmap` | その場限りのキーマップ（リロードで消える） |

> ダッシュボードの `:` で使えるのは「ファイル・バッファ」の表のコマンドだけ。

## 5. クリップボードとレジスタ（本アプリ独自の挙動）

Neovim の `clipboard=unnamedplus`（LazyVim の既定）と同じ動きにしてある。

- `y` `d` `c` `x` などでレジスタ指定なしに取った文字列は、**OS のクリップボードにもコピー**される。
- `p` `P` は**OS のクリップボードの中身を貼り付け**る。他のアプリでコピーした文字列が改行で終わっていれば行単位で貼られる。
- `"ay` `"ap` のようにレジスタを指定した場合、`"_`（ブラックホール）、`"+` などは Vim 標準どおり。
- クリップボードへのアクセスが拒否された場合は、直前にヤンクした内容が貼られる。
- HTTPS でない環境（`navigator.clipboard` が無い）ではエディタ内のレジスタだけで動く。

## 6. 日本語 IME を ON にしたままの操作（本アプリ独自）

IME を切り替えずに Normal モードのキーを打てるようにしてある。

- 全角英数字・記号（`ｊ` `ｄｄ` `：` `／` など）は半角のキーとして扱う（`langmap`）。
- 日本語の記号も対応するキーに読み替える: `・`→`/`、`ー`→`-`、`「`→`[`、`」`→`]`、`、`→`,`、`。`→`.`、`￥`→`\`、全角スペース→`<Space>`
- IME が変換中のまま `gg` のように続けて打っても、メモに文字が入らずキーとして処理される。
- Insert モードで IME 変換中に `Esc` を押すと、変換を取り消したあと Normal モードに戻る。変換中でなければ 1 回で戻る。
- `半角/全角`（Mac は `かな` / `英数`）で IME を切り替えるとモードも追従する。
  - IME を **ON** にしたとき: Normal モードなら Insert モードに入る（`i` 相当）。Insert モードならそのまま。
  - IME を **OFF** にしたとき: Insert モードなら Normal モードに戻る（変換中の文字は確定してから戻る）。Normal モードならそのまま。
  - Visual モードや `d` `f` `"a` などの途中では何もしない。
  - ブラウザは IME の状態を直接教えてくれないので、直前に打った文字キーが IME を通ったかどうかで今の状態を判断し、`半角/全角` でそれを反転させる。Windows の `半角/全角` キーが報告する `Hankaku`/`Zenkaku` は押すたびに交互になるだけで、別のアプリや Ctrl+Space で IME を切り替えるとずれるため、エディタにフォーカスが来てからまだ何も打っていないときだけ使う（Mac の `かな`/`英数` は常にそのとおり）。期待どおりに動かないときは `:KeyLog` に記録されたキーを確認する。
- Android（スマホ）では外付けキーボードの `Esc` が OS の「戻る」として扱われるが、このアプリでは閉じずに `Esc` として処理する（Normal モードに戻る、プロンプトを閉じる など）。画面の「戻る」ボタン・ジェスチャーも同じ動きになる。
- `:KeyLog` で、`Esc` や「戻る」がどう届いたかの記録（アプリを閉じても残る、直近 40 件）を表示する。`:KeyLog!` で消去。文字キーは記録しない。
- `fあ` のように `f` `t` `r` の後の文字は、IME で入力した日本語をそのまま使える。

## 7. ダッシュボードのキー

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 下 / 上へ移動 |
| `g` / `G` | 先頭 / 末尾へ |
| `Enter` / `l` | 選択したメモを開く |
| `n` | 新規メモ |
| `dd` | 選択したメモを削除（`y` で確定、それ以外のキーで取り消し） |
| `r` | リモートと同期（`:Sync`） |
| `/` | 全メモを検索（IME ON で `／` `・` を打っても可） |
| `:` | Ex コマンド入力 |
| `Esc` | 検索中なら検索を解除、そうでなければダッシュボードを閉じる |
| `q` | ダッシュボードを閉じる（開いているバッファへ戻る） |

検索（`/`）:

- 対象はファイル名（拡張子を除く）と本文。大文字小文字を区別しない。スペース区切りで AND 検索。
- 入力するたびに一覧が絞り込まれる。
- `↓` / `<C-n>`、`↑` / `<C-p>` で選択、`Enter` で一致箇所にカーソルを置いて開く、`Esc` で解除。

## 8. 未対応・既知の違い

- 任意のウィンドウ分割（`<C-w>s` `<C-w>v` `:split` `:vsplit`）、タブページ、`:w <名前>` での別名保存は無い。分割は Markdown プレビュー専用。
- `<leader>ff` はまだ fuzzy picker ではなくダッシュボードを開くだけ（M2 予定）。
- `H` `L` `<Space>` は上記のとおり標準の意味から変えている。
- `:map` などで追加したキーマップや `:set` はページを再読み込みすると消える（設定ファイルは無い）。
- `jj` / `jk` での Insert モード脱出は無い（`Esc` / `<C-[>` / `<C-c>` を使う）。

## 9. Markdown プレビュー（本アプリ独自）

LazyVim の markdown extra（markdown-preview.nvim）と同じキー・コマンドで、エディタの横に Markdown の表示を出す。
ブラウザの別タブではなく、画面を分割して同じページの中に出す。

- 横長の画面では左右、縦長の画面（スマホの縦持ちなど）では上下に分割する。
- 入力するとすぐに表示が更新される。保存していない内容も表示される。
- エディタにフォーカスがある間は、プレビューがカーソルのある行の付近まで自動でスクロールする。
- 一度開くと、バッファを切り替えても開いたまま。ダッシュボードを表示している間は隠れる。
- 1 つの改行はそのまま改行として表示する（GitHub のコメント欄と同じ）。`#tag` は色付きで表示する。
- リンクは、`https://` などは新しいタブで開き、`example.md` のような相対リンクはそのメモを開く。

### ウィンドウ操作

| キー / コマンド | 動作 |
|---|---|
| `<leader>cp` / `:MarkdownPreviewToggle` | プレビューの表示 / 非表示 |
| `:MarkdownPreview` / `:MarkdownPreviewStop` | プレビューを開く / 閉じる |
| `<C-w>w` `<C-w><C-w>` `<C-w>p` / `<leader>ww` | エディタ ↔ プレビューのフォーカス移動 |
| `<C-w>h` `<C-w>k` | エディタへ |
| `<C-w>l` `<C-w>j` | プレビューへ |
| `<C-w>c` `<C-w>q` `<C-w>o` / `<leader>wd` / `:close` `:only` | プレビューを閉じる（エディタは閉じない） |
| `:wincmd {c}` | `<C-w>{c}` と同じ |

PC のブラウザでは `Ctrl+W` が「タブを閉じる」に取られて届かないことがある。その場合は
`<leader>ww` / `<leader>wd` か `:wincmd w` を使う。

プレビューにフォーカスがあるとき、ステータスラインのモード表示は `PREVIEW` になる。

### プレビュー内のキー

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑`、`<C-e>` / `<C-y>` | 少しスクロール |
| `<C-d>` / `<C-u>` | 半画面スクロール |
| `<C-f>` / `<C-b>`、`PageDown` / `PageUp` | 1 画面スクロール |
| `gg` / `G` | 先頭 / 末尾へ |
| `H` / `L` | 前 / 次のバッファ |
| `q`、`:q` | プレビューを閉じる |
| `Esc`（Android の「戻る」も） | エディタに戻る |
| `:` | Ex コマンド入力（`:w` などはエディタと同じ） |
| `<leader>…`、`<C-w>…` | エディタと同じ |
