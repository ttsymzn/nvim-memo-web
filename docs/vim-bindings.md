# Vim キーバインド説明書

nvim-memo-web で**いま実際に使える**キー操作の一覧。
エディタ部分は [`@replit/codemirror-vim`](https://github.com/replit/codemirror-vim) 6.2.1 の上に、
LazyVim 風のキーマップとメモアプリ用の Ex コマンドを足したもの。

- leader キーは `<Space>`（表記は `<leader>`）
- 「本アプリ独自」と書いたものは Neovim / codemirror-vim 標準と挙動が違うか、追加したもの

---

## 1. 画面とモード

| 画面 | 説明 |
|---|---|
| ダッシュボード | 起動直後・全バッファを閉じたとき・`:Dashboard` で表示されるメモ一覧 |
| エディタ | メモを編集する画面。上にバッファライン（開いているメモのタブ）、下にステータスラインとコマンドライン |

エディタのモードは Normal / Insert / Visual（`v` `V` `<C-v>`）/ Replace（`R`）。
行番号は LazyVim と同じく **相対行番号**（カーソル行だけ絶対番号）。

---

## 2. 本アプリ独自のキー（エディタ）

| キー | モード | 動作 |
|---|---|---|
| `<C-s>`（Mac は `⌘S` も可） | 全モード | 保存（`:w` と同じ） |
| `H` | Normal | 前のバッファ（`:bprevious`）。※標準の「画面上端へ」は上書き |
| `L` | Normal | 次のバッファ（`:bnext`）。※標準の「画面下端へ」は上書き |
| `<leader><leader>` | Normal | メモ一覧（ダッシュボード） |
| `<leader>ff` | Normal | メモ一覧（M2 で fuzzy picker に置き換え予定） |
| `<leader>fn` | Normal | タイムスタンプ名の新規メモを作り、Insert モードで開く |
| `<leader>bd` | Normal | 今のバッファを閉じる（`:bd`） |
| `<leader>qq` | Normal | 全バッファを閉じる（`:qa`） |

leader の補足:

- `<Space>` を押すとコマンドラインに `<leader>` と表示され、続くキーを待つ。**1 秒**押さないか `Esc` で取り消し。
- 割り当てのない組み合わせは `<leader>xx は割り当てられていません` と表示される。
- `f<Space>` や `d<Space>` のように、文字やモーションを待っている途中の `<Space>` は leader にならず、そのまま Vim に渡る。
- 標準 Vim の `<Space>`（= `l`、右へ 1 文字）は leader に置き換わっているので使えない。

## 3. Ex コマンド

エディタでは `:` で、ダッシュボードでも `:` で入力できる。

### ファイル・バッファ（本アプリ独自）

| コマンド | 動作 |
|---|---|
| `:w` / `:write` | 保存。既存メモは `[nb] Edit:`、新規は `[nb] Add:` の 1 コミット（新規なら `.index` にも追記）。`:w <名前>` は未対応 |
| `:wa` / `:wall` | 変更のある全バッファを保存 |
| `:q` / `:quit` | 今のバッファを閉じる。未保存なら `E37` で止まる |
| `:q!` | 変更を破棄して閉じる |
| `:qa` / `:qall` | 全バッファを閉じてダッシュボードへ。`:qa!` で未保存も破棄 |
| `:wq` | 保存して閉じる |
| `:x` / `:xit` | 変更があれば保存して閉じる（なければそのまま閉じる） |
| `:e <名前>` / `:edit <名前>` | メモを開く。無ければ新規作成。拡張子を省略すると `.md` |
| `:e` | 今のメモをリモートの内容で読み直す（未保存なら `E37`） |
| `:e!` | 変更を破棄して読み直す |
| `:new` | タイムスタンプ名の新規メモ |
| `:bn` / `:bnext`、`:bp` / `:bprevious` | 次 / 前のバッファ |
| `:bd` / `:bdelete`（`:bd!`） | 今のバッファを閉じる |
| `:ls` / `:buffers` | バッファ一覧（`%a` = 表示中、`+` = 未保存） |
| `:Dashboard` | メモ一覧を開く |
| `:Sync` | リモート（GitHub）の変更を取り込む |
| `:Logout` | 保存している GitHub token を削除してログアウト |

### codemirror-vim 標準（エディタ内のみ）

| コマンド | 動作 |
|---|---|
| `:s/pat/rep/[gci]` / `:%s/…` | 置換（範囲指定・`c` で確認） |
| `:g/pat/cmd`、`:v/pat/cmd` | 一致する行 / しない行にコマンド実行 |
| `:d`、`:y`、`:j` | 行の削除・ヤンク・結合（範囲指定可） |
| `:normal {keys}` | Normal モードのキーを実行 |
| `:sort` | 行のソート（`!` で逆順、`n` 数値、`u` 重複除去 など） |
| `:noh` | 検索ハイライトを消す |
| `:u` / `:redo` | アンドゥ / リドゥ |
| `:set {opt}` | オプション変更（例 `:set ignorecase`） |
| `:reg` | レジスタの中身を表示 |
| `:delm {marks}` | マークを削除 |
| `:{数字}` | その行へ移動 |
| `:map` `:nmap` `:noremap` など / `:unmap` | その場限りのキーマップ（リロードで消える） |

> ダッシュボードの `:` で使えるのは「ファイル・バッファ」の表のコマンドだけ。

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` / 矢印 | 左・下・上・右 |
| `gj` `gk` | 折り返し表示上の行で上下 |
| `w` `b` `e` `ge` / `W` `B` `E` `gE` | 単語単位（大文字は空白区切り） |

### 検索

| キー | 動作 |
|---|---|
| `/pat` `?pat` | 前方 / 後方検索（正規表現） |

### 編集

| キー | 動作 |
|---|---|
| `i` `a` `I` `A` `o` `O` `gI` `gi` | Insert モードへ |
| `Esc` / `<C-[>` / `<C-c>` | Normal モードへ戻る |
| `x` `X` `s` `S` `r{c}` `R` | 1 文字削除・置換など |

| `c{motion}` `cc` `C` | 変更（削除して Insert） |
| `y{motion}` `yy` `Y` | ヤンク |
| `p` `P` / `]p` `[p` | 貼り付け（インデント合わせ版） |

| `>` `<` `=` | インデント増減・整形 |
| `~` `g~` `gu` `gU` | 大文字小文字の切り替え |
| `gq` `gw` | 行の整形（折り返し） |
| `<C-a>` `<C-x>` | 数値の増減 |
| `u` / `<C-r>` / `U` | アンドゥ / リドゥ |

| `q{reg}` … `q` / `@{reg}` `@@` | マクロ記録 / 再生 |

### テキストオブジェクト（`d` `c` `y` `v` などの後に）

`iw` `aw` `iW` `aW`（単語）、`is` `as`（文）、`ip` `ap`（段落）、
`i(` `a(` `ib`、`i[` `a[`、`i{` `a{` `iB`、`i<` `a<`（括弧）、
`i"` `a"` `i'` `a'` `` i` `` `` a` ``（引用符）、`it` `at`（タグ）

### Visual モード

| キー | 動作 |
|---|---|
| `v` / `V` / `<C-v>` | 文字 / 行 / 矩形選択 |
| `gv` | 直前の選択範囲を再選択 |
| `o` | 選択の反対端へ |
| `I` `A`（矩形選択中） | 複数行に同時挿入 |
| 選択後に `d` `c` `y` `p` `>` `<` `~` `u` `U` `J` `:` など | 選択範囲に適用 |

### Insert モード

| キー | 動作 |
|---|---|
| `<C-w>` | 直前の単語を削除 |
| `<C-u>` | 行頭まで削除 |
| `<C-r>{reg}` | レジスタの中身を挿入 |
| `<C-o>` | Normal モードのコマンドを 1 つだけ実行 |
| `<C-t>` / `<C-d>` | インデント増 / 減 |

## 5. クリップボードとレジスタ（本アプリ独自の挙動）

Neovim の `clipboard=unnamedplus`（LazyVim の既定）と同じ動きにしてある。

- `y` `d` `c` `x` などでレジスタ指定なしに取った文字列は、**OS のクリップボードにもコピー**される。
- `p` `P` は**OS のクリップボードの中身を貼り付け**る。他のアプリでコピーした文字列が改行で終わっていれば行単位で貼られる。
- `"ay` `"ap` のようにレジスタを指定した場合、`"_`（ブラックホール）、`"+` などは Vim 標準どおり。
- クリップボードへのアクセスが拒否された場合は、直前にヤンクした内容が貼られる。
- HTTPS でない環境（`navigator.clipboard` が無い）ではエディタ内のレジスタだけで動く。

## 6. 日本語 IME を ON にしたままの操作（本アプリ独自）

IME を切り替えずに Normal モードのキーを打てるようにしてある。

- 全角英数字・記号（`ｊ` `ｄｄ` `：` `／` など）は半角のキーとして扱う（`langmap`）。
- 日本語の記号も対応するキーに読み替える: `・`→`/`、`ー`→`-`、`「`→`[`、`」`→`]`、`、`→`,`、`。`→`.`、`￥`→`\`、全角スペース→`<Space>`
- IME が変換中のまま `gg` のように続けて打っても、メモに文字が入らずキーとして処理される。
- Insert モードで IME 変換中に `Esc` を押すと、変換を取り消したあと Normal モードに戻る。変換中でなければ 1 回で戻る。
- Android（スマホ）では外付けキーボードの `Esc` が OS の「戻る」として扱われるが、このアプリでは閉じずに `Esc` として処理する（Normal モードに戻る、プロンプトを閉じる など）。画面の「戻る」ボタン・ジェスチャーも同じ動きになる。アプリを開いて一度も画面に触れていない状態だけは「戻る」で閉じる（ブラウザの制約）。
- `fあ` のように `f` `t` `r` の後の文字は、IME で入力した日本語をそのまま使える。

## 7. ダッシュボードのキー

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 下 / 上へ移動 |
| `g` / `G` | 先頭 / 末尾へ |
| `Enter` / `l` | 選択したメモを開く |
| `n` | 新規メモ |
| `r` | リモートと同期（`:Sync`） |
| `/` | 全メモを検索（IME ON で `／` `・` を打っても可） |
| `:` | Ex コマンド入力 |
| `Esc` | 検索中なら検索を解除、そうでなければダッシュボードを閉じる |
| `q` | ダッシュボードを閉じる（開いているバッファへ戻る） |

検索（`/`）:

- 対象はファイル名（拡張子を除く）と本文。大文字小文字を区別しない。スペース区切りで AND 検索。
- 入力するたびに一覧が絞り込まれる。
- `↓` / `<C-n>`、`↑` / `<C-p>` で選択、`Enter` で一致箇所にカーソルを置いて開く、`Esc` で解除。

## 8. 未対応・既知の違い

- ウィンドウ分割（`<C-w>s` `:split` `:vsplit`）、タブページ、`:w <名前>` での別名保存は無い。
- `<leader>ff` はまだ fuzzy picker ではなくダッシュボードを開くだけ（M2 予定）。
- `H` `L` `<Space>` は上記のとおり標準の意味から変えている。
- `:map` などで追加したキーマップや `:set` はページを再読み込みすると消える（設定ファイルは無い）。
- `jj` / `jk` での Insert モード脱出は無い（`Esc` / `<C-[>` / `<C-c>` を使う）。
